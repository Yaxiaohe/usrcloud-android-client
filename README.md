# 有人云巡站（Android）

[有人云](https://www.usr.cn) 平台的第三方 Android 客户端：批量巡检设备、自动截图归档、
离线/数据陈旧告警、历史数据折线图。APK 约 1.5 MB。

当前版本 **v0.40.04**（与界面「关于」页显示一致）。

> 本仓库是**干净版本**：不含任何账号、密码、登录缓存或巡检数据，也不含任何公司标识。
> 装好后在「账号」页自己添加账号。

## 一、功能

- **巡站**：按账号批量巡检设备，一台一张卡片图，按批次存进相册目录，跑完自动打包 zip，
  走系统分享面板发出去
- **巡站结果可筛**：总数 / 在线 / 离线·陈旧 / 自定义，点哪个数字就只看哪一类，
  还能和站名搜索叠加；「自定义」可以按变量读数筛，比如「回水温度 < 30」
- **补跑**：只跑这一轮没取到的站，结果盖回原表，不用整批重来；单张图也能重拍
- **监控**：后台常驻，按规则比对并推通知，离线、恢复都提醒，重复告警去重；
  规则可以起名字，通知里一眼看出是哪条规则报的
- **历史**：自动采样留档（值变了才写），可查 6 / 24 小时折线；能导出、导入，也能按需清理
- **排序与置顶**：变量顺序可自己排；常看的站点置顶，各页都排在最前
- **账号**：账号表可以在界面里编辑，也可以直接用文本编辑器改原始表格
- **在线更新**：关于页点「检查更新」就能查、下、装一条走完，装之前先核对安装包；
  直连不通时会自己换一条线路重试，装完照样核对；每天第一次打开会自动查一次，没有新版不打扰

## 二、更新记录

### v0.40.04 修订

**一、「检查更新」连不上时会自己换一条线路。**

手机网络下访问项目主页经常连不通 —— 同一个 WiFi 上电脑能打开，手机上却报「连不上项目主页」。
现在一条线路走不通就自动换另一条再试，走通过的那条会记住，下次先用它；
查发布、下安装包两段都换。两条都不通才报错。

失败提示也分开了：连不上、超时、对方暂时不让访问，三种说的不是同一句话，
照提示换网络或者过一会儿再点就行。

**二、规则里三个框的说明重写了。**

上一版把说明写成了名词短语（「名称中包含某线路二字的设备」），看不出是在讲规则，
设备名这一句连动词都没有，还漏了带 `*` 怎么算。

现在三栏一个句式「写什么 → 只匹配什么」，并且和实际行为一一对过：

| 写法 | 意思 |
| --- | --- |
| `*` 或留空 | 全部，不筛 |
| 写几个字 | 名字里含这几个字就算 |
| `=` 开头 | 一字不差才认 |
| 带 `*` | 按 `*` 切段，命中任一段就算 |

### v0.40.03 修订

**一、异常提醒的三个框，写法统一了。**

以前「账号」「设备名」要把名字写全，写半截不算；「变量名」却是写几个字就算。
一张表两种规矩，照着提示写还一条提醒都不来，也不报错。

现在三个框一个写法：

| 写法 | 意思 |
| --- | --- |
| `*` 或留空 | 全部，不筛 |
| 写几个字 | 名字里含这几个字就算 |
| `=` 开头 | 一字不差才认 |
| 带 `*` | 按 `*` 切段，命中任一段就算 |

每栏标题上都写了例子（填什么、命中什么），填的时候一眼能对上。

**二、「类型」不再弹系统那个绿圆钮单选框。**

改成软件自己的白底蓝字选择行，点一下展开、选完立刻回填。跟其它弹窗一个样式，
也不会再出现上面写着「设备离线」、其实选的是「数值越限」。

**三、账号卡片上的勾选框不再跟着跳。**

卡片多出「过滤 N 台」一行时会变高，勾选框原来跟着往下挪，看着像位置在动；
现在统一贴顶，有没有那行字都一样高。

**四、顶部统计条选中时左边不缺角。**

选中的格子是蓝色边框，原来左边被那条灰色分隔线压掉一小段；现在选中时这条线让开，
蓝框四边完整。

### v0.40.02 新增

**一、关于页多了「检查更新」。**

点一下就去项目主页看有没有新版：有的话写明版本号、安装包多大、本次改了什么，
点「下载更新」直接下到手机上，下完自动核对，核对通过再交给系统安装器，按提示装完即可。
装完账号、历史、截图都还在。

每天第一次打开 App 时会自动查一次：没新版、没连上，都一声不吭；只有真有新版才弹窗。
想手动查随时点按钮，不受一天一次限制。

**二、清理往期批次：数字和提示都算准了。**

以前清理完只报「批次目录数」，而历史压缩包是平铺在内部目录里的，一个都没被算进去 ——
明明删掉几十个包，提示却说「没有往期批次可清理」。
现在压缩包和批次分开算，一起写进提示，还带上释放了多少 MB；最近一次始终保留。
确认框里也写清了会清掉哪些东西。

### v0.39 修订（版本号不变）

**「数据陈旧」不再算在线，归到「需重取」。**

设备行上明明写着「数据陈旧」，仪表却把它算进「在线」，第三格只写「离线(无数据)」——
一台设备看着既在线又没数据。补跑那边同样漏掉，陈旧的站点只能整批重来。

现在只有真正在线才算有数据：仪表第三格改成「离线/陈旧」，补跑按钮改成
「只跑需重取的 N 台」，一次把这些站补上。仪表、列表、导出口径一致，
按钮写几台就真跑几台。

### v0.39 新增

**一、巡站结果按状态筛。**
结果卡上方一排统计：总数 / 在线 / 离线·陈旧 / 自定义。点哪个数字，下面列表就只剩哪一类，
搜索词可以和筛选叠加（结果卡会写「搜 X · 在线」）。统计按全部站点算，不受搜索词影响，
所以「总数 = 在线 + 离线·陈旧」当场能验算，也不会出现「按钮写 3 台、导出却是 5 张」。

**二、「自定义」筛选：按变量值筛。**
长按「自定义」（或点旁边的「设置条件」）可以配多条规则，形如「回水温度 < 30」：
变量名、比较符、数值，支持多条，也能选「与 / 或」。用的是截图那一刻的真实读数，不是事后重查。
没有数值的旧结果按「不满足条件」处理。

**三、监控规则：变量名前面加 `=` 表示一字不差。**
以前只能部分包含：想只看「进水温度」，填「温度」会把「风机化霜出水温度」也带进来。
现在默认仍是部分包含（平台把名字改成「进水温度T2」照样命中），加 `=` 就是完全一致。
输入框下面实时提示当前是哪种匹配，规则列表里也带出 `=`，不会以为没生效。
带 `*` 的片段匹配保持原样。

设备名那一栏的说明也改准了：原来写「写「某线路」= 名字里含某线路」，实际不带 `*` 是精确相等，
照着填一条提醒都不会来。现在写明「写「某线路*」= 名字含」。

**四、巡站页重排。**
账号选择改成两列，不再把开始按钮顶到下面；「巡站进度」移到控制区下方，点完开始一眼看到第几台；
截图保存路径挪到页尾；完成提示写实际跑完的时刻，重启后还能读到。

### v0.38 修订（版本号不变）

**一、修「小程序里有数，监控页却全线离线、所有变量是 -」。**
账号下设备一多，同一轮里靠后的那些常常一条值都拿不到，拿回来的是空数据，外形跟
「设备真的没数据」一模一样，于是被判成了离线。现在一个账号一次问完，一轮里的来回少了很多；
万一这一轮还是没取到，就沿用上一轮状态、不参与告警，免得同一次没取到就按旧状态反复报警。

**二、「设备本身显示在线、却没读到值」不再判离线。**
现在标成「采集异常」，展开区写一行原因：这一轮没查到、没权限、还是网络不通，分开说。
截图上也把原因印在图上，不再只写「未能读取到变量数据」让人以为站点坏了。

**三、巡站可以只补跑没数据的站。**
上一轮结果留作底稿，补跑只跑离线 / 采集异常 / 出错的那几台，跑完把新结果盖回去，
没得跑时会给一句原因。补跑只报这一轮，不混上一轮的在线台数。

**四、截图弹窗里能单张重拍。**
只重跑这一台，后台跑、界面不冻。定位按设备编号，站名会重名、会被改，靠名字找不准。

**五、巡站页的「选择站点」换成一个搜索框。**
设备一多，在勾选弹窗里翻半天。现在结果列表上方直接搜站名或编号，输入即筛，
台数跟着变成「2 / 22」，补跑、重拍、切页回来筛选状态都还在。

## 三、编译

前置：JDK 17、Android SDK（compileSdk 34）。Gradle 不用装，仓库自带 Wrapper（8.7）。

```bash
# 告知 SDK 位置（该文件不入库）
echo "sdk.dir=/path/to/Android/sdk" > local.properties      # macOS / Linux
echo sdk.dir=C:\\path\\to\\Android\\sdk  > local.properties # Windows

# 构建
./gradlew assembleRelease          # macOS / Linux
build.bat assembleRelease          # Windows（自动探测 JDK 与 SDK）
```

首次运行 Wrapper 会下载 Gradle 8.7（约 120 MB），之后走缓存。
`build.bat` 会依次从环境变量、常见安装位置、`local.properties` 里找工具链，
找不到会明确报错，不会静默失败。

### 「检查更新」查哪个仓库

仓库里的 `assets/update.conf` 只写一个仓库名：

```
src=github
repo=Yaxiaohe/usrcloud-android-client
```

自己编译要发自己的版本，把 `repo` 改成「你的用户名/仓库名」；
不想要这个功能就删掉 `assets/update.conf`，关于页不会出现「检查更新」按钮，程序也不联网。

### 签名

仓库**不含签名密钥**。没有密钥时自动回落到 debug 签名，保证 clone 下来就能打出可安装的包。
要发布自己的版本，请自建密钥：

```bash
keytool -genkeypair -v -keystore keystore/usrcloud.jks -keyalg RSA -keysize 2048 \
        -validity 10950 -alias usrcloud -storepass <密码> -keypass <密码>
```

密码不要写进仓库，可用环境变量传入：

```bash
set USRCLOUD_STORE_PWD=xxx
set USRCLOUD_KEY_PWD=xxx
```

### 版本号怎么改

三处必须同步，改一处会不一致：

| 位置 | 字段 |
| --- | --- |
| `app/build.gradle` | `versionCode` / `versionName` |
| `Core.java` | `APP_VERSION`（界面「关于」读的是这个） |
| `index.html` | 页头的版本号 |

另外脚本里还有一个版本读不到时的兜底串，一起改。

## 五、注意

- 巡站时尽量别切走太久，系统可能回收后台进程
